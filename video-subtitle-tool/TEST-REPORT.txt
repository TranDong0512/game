LỖI ĐÃ TÁI HIỆN VÀ SỬA TRONG CLI
1. Đọc HF_API_KEY khi import trước dotenv: chuyển sang đọc lúc gửi request.
2. Payload nhận dạng sai: gửi base64 JSON và yêu cầu return_timestamps.
3. ASR không có timestamps vẫn tạo cue 0->0: báo lỗi rõ ràng, kiểm tra mốc thời gian.
4. Dịch đọc generated_text thay vì translation_text: đọc đúng kết quả translation API.
5. Làm tròn SRT thành 59,1000: làm tròn tổng milliseconds trước khi tách giờ/phút/giây.
6. Song ngữ trùng hai dòng khi bỏ dịch: loại dòng trùng.
7. Không kiểm tra mode/thời gian cue: bổ sung kiểm tra và test.
8. Mode original vẫn gọi dịch: bỏ qua dịch khi chỉ yêu cầu bản gốc.
9. File trung gian bị ghi đè giữa các lần chạy: dùng thư mục job riêng.
10. Gỡ tùy chọn vô hiệu hóa kiểm tra chứng chỉ khi tải; không tải cả playlist.
11. Cập nhật Axios lên ^1.20.0 để xử lý các advisory npm audit phát hiện.
12. Chuyển URL Hugging Face từ api-inference sang router; cho phép HF_ASR_URL tùy chỉnh.

ANDROID
- Viết ứng dụng native, chạy trực tiếp trên điện thoại, không cần máy tính/server riêng.
- Chọn file video/âm thanh qua trình chọn file hệ thống hoặc nhập URL HTTP(S).
- Tải audio qua yt-dlp; giải mã bằng MediaExtractor/MediaCodec, WAV mono 16 kHz.
- Chia đoạn 5 phút, ghi nhận thời gian bắt đầu thực của đoạn; gọi Groq Whisper verbose_json.
- Dịch theo nhóm, kiểm tra số câu và kiểu dữ liệu trả về; xuất SRT gốc/dịch/song ngữ.
- Xử lý nền, thông báo, hủy tác vụ, retry API 429/5xx có giới hạn.
- Khi lỗi dịch, cho phép xuất bản gốc đã nhận dạng; dọn file tạm.
- API key nhập trên máy, mã hóa AES-GCM với Android Keystore, không nhúng key trong APK.
- Xuất SRT qua Storage Access Framework, không xin quyền truy cập toàn bộ bộ nhớ.

- Thử nghiệm ban đầu dùng FFmpeg bị thiếu đường dẫn libc++: đã xác định và sửa đường dẫn.

GIỚI HẠN ĐÃ BIẾT / CHƯA KIỂM THỬ
- Chưa gọi API nhận dạng/dịch với key thật; chưa đánh giá chất lượng phụ đề trên video thực.
- Chưa test tải video từ từng website hoặc các URL cần đăng nhập/CAPTCHA/DRM.
- Chưa test trên điện thoại ARM thật; APK chứa ARM64/ARMv7/x86_64, minSdk 26 (Android 8).
- Bản Android cần Internet và GROQ API key (khác với HF_API_KEY của CLI).
  Dữ liệu âm thanh/văn bản gửi trực tiếp tới Groq, hạn mức và chi phí tùy tài khoản/model.
- CLI Hugging Face phụ thuộc provider có phục vụ model tại thời điểm chạy; router mới không
  bảo đảm các model cấu hình sẵn luôn khả dụng. Có thể cấu hình endpoint ASR riêng.
- Định dạng Android hỗ trợ phụ thuộc codec của điện thoại. Codec lạ có thể không giải mã được.
- APK xuất file SRT riêng; chưa ghép phụ đề vào video và không lưu bản video tải từ URL.
- Giới hạn file local 2 GB; URL giới hạn 500 MB khi công cụ tải biết kích thước.
- Hệ điều hành có thể dừng tác vụ dài khi thiếu tài nguyên; chưa có resume sau process death.
- Resampling WAV hiện dùng lấy mẫu đơn giản; không phải bộ chuyển đổi âm thanh chất lượng studio.
